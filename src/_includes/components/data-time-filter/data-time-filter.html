{# 「資料時間篩選」整列（近24小時／上週／上個月／時間區間＋起訖欄）。 5-3 統計模組與 5-4 覆蓋缺口逐字相同（約 45 行），§3-3「同一段版面出現在 2 頁以上就抽成元件」。 抄本已經開始分岔：兄弟列（查詢資料類型）一頁寫 role="group"、另一頁寫 role="radiogroup"—— 那一列是純 radio，`radiogroup` 才對（見 data-type-filter）。 **但這一列不是** `radiogroup`：`field-with-input-group` 的構造讓它必然含兩個文字欄 （起訖時間），`radiogroup` 的 owned element 只能是 radio，報讀器會把那兩格念成單選成員。 故這一列維持 `role="group"`。 參數（使用頁在 include 前 set，見 §3-2/§6）： timeFilterName —— radio 的 name（同頁多組要不同：5-3 是 data-time、5-4 是 gap-time） timeFilterLabelId —— 群組標題的 id（供 aria-labelledby 指到；同頁唯一） timeFilterChecked —— 預設選中哪一顆：last24h / lastWeek / lastMonth / range（不給＝一顆都不選） 起訖欄是 flatpickr 的掛點（真 app js/main.js 綁 .start-date/.end-date），切版不引 vendor、 只保留 class 與 disabled 初始態；`.time` 是 form-control 的日曆圖示變體（`.field:has(> .form-control.time)::after`）， 4-1 的同型欄位有、這兩頁原本漏掉。 `.field-with-input-group` / `.field-with-input` / `.with-input` 是**真 app 的掛點** （js/main.js:429-453：選了哪顆 radio 就解除它附屬輸入框的 disabled），不是無主 class—— 那個 `disabled` 初始態的意義就是「還沒選時間區間」。行為由 `ui/field-with-input` 當場做（§5 ④）。 #}
