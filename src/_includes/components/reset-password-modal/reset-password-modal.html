重設這一位的密碼：

{# **按下去會發生什麼，寫在按下去之前**（§3-2「後果寫在做那個決定的控制項旁邊」）： 重設不只是換一組密碼，它有兩個管理者未必預期得到的連帶後果，而**兩個都要講** （§3-2「只講對一半也是同一種說謊」）——兩條端點路徑逐字相同，各自都做這兩件事： · `must_change_password = True` ⇒ 那位成員下次登入時會被要求先改掉這一組。 · `token_version += 1` ⇒ 該成員**所有**既有 session 立刻失效，正在用的裝置全部 被登出。少了這一句，管理者只會知道自己換了一把「之後才要用的鑰匙」， 而實際上他剛把對方從所有裝置上踢了下來。 出處＝product 的 `reset_password`（租戶端）與 `platform_reset_password`（平台端）。 這一句是**代價說明、不是警示**：重設本來就是管理者要做的事，什麼都沒有被擋下來， 所以走中性的 `text-gray`，紅字留給「有東西壞了或被擋下」（§4）。 #}

重設之後，這位成員目前登入中的裝置會全部被登出，而且下次登入時必須先變更這一組密碼。
