編輯 Skill

小寫英數與連字號，長度 1-64；不可以連字號開頭／結尾，也不可連續連字號。此名稱同時就是 agent 看到的工具名。

請同時寫「這個 skill 做什麼」與「什麼時候該用它」——這是 agent 判斷要不要呼叫它的唯一依據，寫得含糊就不會被觸發。

被呼叫時才載入，當作這個 skill 的系統提示詞。要照順序執行就在這裡寫清楚步驟。

可使用的工具

只有勾選的工具能被這個 skill 使用；沒勾的在執行時根本不存在，不是「不准用」而是「用不到」。

被引用的 skill 會成為這個 skill 可呼叫的工具。不可互相引用成環，巢狀深度上限 3 層。

JSON Schema，決定 agent 呼叫這顆工具時要給什麼參數（頂層必須是 object；不可宣告 document_ids／indexes／dsl）。留空＝agent 用一句自然語言的 task 呼叫它。

這個 skill 的子迴圈最多來回幾輪（1-20）。設太小會讓它還沒做完就被截斷。
