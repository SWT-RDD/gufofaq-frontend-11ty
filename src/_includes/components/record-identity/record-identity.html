{# 一筆健檢記錄的**可讀身分**。使用頁在 `{% for %}` 內 `{% set recordIdentity = … %}` 之後 include。 參數 `recordIdentity = { title, titleChars, titleSource, filename, row, unavailableReason }`。 「這一筆為什麼讀不出來」的那一整段完整說明**不在這裡畫**：它是一段獨立的說明文字， 由「涉及的記錄」那一列在身分後面另起一段，處置選項那幾格只需要短標記。 種類標記走 `{% if %}` 鏈、key 逐條寫成字面，**不走「示範列上帶一組 label／key」那套投影** （本頁的 `severityLabel`／`severityKey` 是那一套）：投影出來的 `data-i18n="{{ … }}"` 是模板 變數，繫結在巢狀集合裡解不開，i18n 對帳掃描讀不到它指向哪一顆 key。 那一族並非完全沒有網：還有一張後備網不看繫結、只在同一個 `{ … }` 裡配 `Key` ↔ `Label`。但那是一張**後備**的網、而且**輸給**讀得到繫結的那一條； 寫成字面的三顆從一開始就受最直接的那條逐字對帳守門，不必依賴任何後備網。 為什麼在意這個差別：只靠後備網守住的 key，一旦抽取器的形狀對不上就整族靜默漏掉 （`settings.outputRule*Desc` 就是這樣漏過），而漏掉時畫面上沒有任何訊號。 放 `components/` 而不是 `ui/`：它在自己的 markup 寫了 `ui/inline-code` 的 class （GUIDELINE §1-1 的「用到其他元件」第二種形式）。 **為什麼是元件**：同一頁出現五處——「涉及的記錄」那一列，以及合併／停用／取代／補寫四支 處置的選項清單。五份抄本改一處就會漏（GUIDELINE §3-3 第 2 條），而漏掉的那一份正是使用者 按下去的那一格。 ## 種類標記與標題同進同出 `title` 有**三種來源**（`titleSource` 的值域就是下面這三顆，在這裡宣告一次，就是正本）， 三種東西長得都像標題： · 逐列匯入的一列 → 那一列的**標題槽**（`title_slot`；合併時真的寫回來源檔的那個 字串就是它，讀的是同一格） · 資料夾匯入的整份文件 → **原始檔名**（`filename`；不是內容，也不是落地 檔名——這一型的標題槽恆為空是刻意的） · 查無主題 → 它代表的那個**問法**（`no_answer_question`；它本來就不是知識庫裡的一筆記錄） 使用者是**據此按下「保留這一筆」**的，而那會改資料。把一份 PDF 的檔名與一則問答的問法混 在一起呈現，那句話的意思就變了——所以種類標記不是只寫在清單那一處，它跟著標題走。 ## 檔案與列號不是裝飾 兩筆近似重複的問法常常**逐字相同**（那正是它們被抓出來的原因）。同名時只有 `filename` 與 `row` 分得開，少了它們，radio 上會出現兩個一模一樣的選項。整份文件與查無主題沒有列號 （那兩型的 `row` 是 null），查無主題連檔案都沒有，所以那兩段各自不渲染、不是印一個 0 或一格空白。 **`titleSource == "filename"` 那一型不重畫檔案**：這一型的標題與檔名是由**同一個 值**構造的，兩格逐字相同。照畫就是同一個檔名在同一行印兩次，而「檔案」那一段存在的理由是 「同名的兩筆靠它分得開」，對這一型完全不成立（一檔一筆，沒有同名可分）。檔名太長時原文長度 仍由截斷提示說出來（被截的就是那個檔名）。 ## 空標題不是「讀不出來」 `title` 是空字串＝**這一筆的標題欄留白**（一件關於資料的事實，處置是回去補標）； `title` 為 null ＝**標題讀不出來**。兩者都退成一格空白的話，畫面對兩件要人做不同事的事說 同一句話。讀不出來時畫的是一句固定的短標記 ＋ **原因代碼**（`unavailableReason` 的值域是 `record_not_found`／`source_unreadable`／`topic_question_missing` 三顆，在這裡宣告一次， 就是正本）：代碼是資料、不翻，畫面也不另立一張「代碼 → 中文」的映射表——說得出 「這代表什麼」的那整段話由「涉及的記錄」那一列在身分後面另起一段給（見上），這裡只畫代碼。 ## 截斷跟著標題走 `title` 只給開頭那幾個字，`titleChars` 一律是**原文**長度。只印前 N 字而不說原本多長，讀的人會以為那就是全部——而這裡正是他要據以選擇的那一格，所以截斷的 提示在每一處都出現，不是只出現在清單那一份。 #} {% if recordIdentity.unavailableReason %}（讀不出這一筆的標題） {{ recordIdentity.unavailableReason }}{% else %} {% if recordIdentity.titleSource == "title_slot" %}〔資料列〕{% elif recordIdentity.titleSource == "filename" %}〔整份文件〕{% elif recordIdentity.titleSource == "no_answer_question" %}〔使用者的問法〕{% endif %} {% if recordIdentity.title %}{{ recordIdentity.title }}{% else %}（這一筆的標題欄是空的）{% endif %} {% if recordIdentity.titleChars > recordIdentity.title.length %}（只顯示開頭，原文共 {{ recordIdentity.titleChars }} 字）{% endif %} {% endif %} {% if recordIdentity.filename and recordIdentity.titleSource != "filename" %}{{ recordIdentity.filename }}{% endif %} {% if recordIdentity.row %}第 {{ recordIdentity.row }} 列{% endif %}
