**最常見**：匯入當下多半就是這個，所以 1-1-6 的示範是它，1-2-1 那批也留一檔演它。 **絕對不可以看起來像成功**：這整條缺陷的成因就是「還不知道」與「成功了」同形， 所以它不是綠勾而是進行中的藍，並用一句 hint 告訴使用者可以稍後回來看。 succeeded 綠（`.is-pass`）「已寫入索引」——上游確認寫進索引了。沒有 hint（沒有事要做）。 failed 紅（`.is-fail`）「寫入索引失敗」——上游明確失敗（`failed_count` 可能 > 0，也可能 整檔被拒）。正確動作＝修好資料重匯。 unknown 黃（`.is-warn`）「查不到結果」 ——**查結局這件事本身失敗了**，不是匯入失敗。 資料已送出、管道已派工 ⇒ 正確動作＝拿關聯編號問維運，**絕對不要重匯**。 **視覺不可以與 failed
