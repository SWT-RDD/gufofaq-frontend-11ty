{# 展示片段（只被元件庫頁 include）：整頁錯誤版型 `.error-page` 的另外**四**種狀態。前兩顆是 **公開分享頁 `shared.html`（`src/pages/shared/shared.html`）** 的錯誤態，後兩顆是**站內任何一頁 被 403 擋下時的整頁態**。四顆的共同點是「那一頁靜態稿一次只演得出一態」，而版型是同一顆原子 ——並排放在元件庫才看得出它們的差別在文案（§5：分支的單位是版型，一處演過就夠）。 ① HTTP 404：連結無效／已撤銷／已過期。上游把「租戶被凍結／到期」「租戶的 history 功能被平台關掉」 「上游查無這筆 chat log」全部收斂成同一個 404（gufofaq-saas product 的 `view_shared` 逐個 `raise` 都是 404，且註解寫明「不分辨…不洩漏租戶狀態」）——所以畫面上也只有 這一句，不替訪客猜是哪一種。 ② HTTP 429：連結**還有效**，只是此刻存取太頻繁（product 的 `enforce_shared_link_rate_limit`，per-tenant 桶）。 為什麼 ①② 分成兩顆 key 而不是共用一句：寫成「找不到」會讓使用者以為連結被撤銷、回頭去跟人要一條 新的——而他其實只要等一下。反過來把 404 寫成「太頻繁」則會讓人一直重試一條永遠打不開的連結。 ①② 都**沒有動作鈕**（404.html 那一份有「回頁面目錄」）：公開分享頁的訪客沒有登入態，也沒有目錄 可回；能做的動作只有稍後重試。 ── ③④：整頁 403──────────────────────────────────────────────── **這一族的落點就在這裡**——它同時活在 React 那一側（gufofaq-saas 的 `apps/web`： `platform.forbidden`／`users.forbidden`／`retrieval.forbidden` 三顆，橫跨十條路由， `apps/web/app/(app)/` 底下的 audit／conversation-settings／glossary／groups／mcp-servers／ platform／qa-sets／regression／skills／users，反查 `grep -rln 'users.forbidden\|retrieval.forbidden\|platform.forbidden' apps/web/app`）。 走得到的路徑很平常：導覽入口是照 `data-platform-role`／`data-capability` 隱藏的，但**擋不了網址列**——把網址記在書籤、或別人貼一條 連結過來，頁面就打得開，而該頁的讀取端點回 403。 不畫這一態的後果是**整頁只剩一列麵包屑**：空白與「你被擋住了」在畫面上長得一模一樣（§5 空狀態 正典要答得出「空著代表什麼／好消息還是壞消息／下一步按哪裡」，一片空白三件都答不出來）。 **為什麼收進 `.error-page` 而不是在那十頁各放一顆 `.hidden` 的紅字**： · §3-3 第 1 條——出現在 2 頁以上就要切成元件；十份抄本注定分岔。 · 這一態的單位是**整頁**（頁面內容一個區塊都不剩），而站上已經有一顆專門畫「整頁沒有東西 給你看」的原子，就是這一顆（404／429 用的同一個）。 · 麵包屑與導覽仍由 `page-shell` 畫著，所以使用者離得開；`.error-page` 只換掉內容區。 React 端（gufofaq-saas 的 `apps/web`）＝該路由的讀取端點回 403 時，整個內容區換成這一塊 （`if (forbidden) return …` 那個位置），而不是塞一行 `

` 的紅字。 **為什麼是兩顆 key、不是三顆也不是一顆**：分界是**收件人**，不是頁面，也不是哪一支 `require_*`。 ③ 租戶層（`require_capability`／`require_admin` 的 403，涵蓋 5-2／5-5-1／5-5-2／5-7／3-2／3-3／ 3-4／2-2-4 這一族）——找得到人開通，收件人是**貴租戶的管理者**（與 §4 那句 「權限不足，無法<動詞>——請找貴租戶的管理者開通」同一個收件人）。 ④ 平台層（`require_platform_admin`／`require_platform_auditor` 的 403，涵蓋 5-6-1 那一族與 5-6-2／5-6-3）——租戶管理者也給不了，收件人是**平台系統管理員**。 ⚠️ **④ 不寫「僅限平台系統管理員」**：5-6-1 與 5-6-3 兩頁的頁層閘是 `require_platform_auditor` （product），平台稽核員進得來——寫成「僅限系統管理員」是一句對兩頁不成立的 斷言。改講「沒有平台角色」，那對 auditor 與 admin 兩級都成立。 ⚠️ 平台層那一顆**不併進 ③**：租戶管理者對它一點辦法都沒有，把他指去找租戶管理者是把人送去一個 幫不了他的地方（§4「兩組不同的鍵…失敗的方式也不同」，同 `data-tenant-feature` 要另開一段的理由）。 ③④ 同樣沒有動作鈕：導覽列就在上面，而「回首頁」這種鈕會暗示這一頁待會兒可能就好了。 #}
