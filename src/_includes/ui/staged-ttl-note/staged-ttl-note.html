{# 暫存檔存活時間的常駐提示：匯入流程裡「剛上傳的檔還沒送出」那幾頁共用的一句話。 §3-3「出現在 2 頁以上 → 切」——這一段在那幾頁上逐字相同，各自手抄的話，改時數或改措辭 只會有一頁跟著改，而每一頁分開看都很合理。 住在哪一頁（雙向，§1-2：三頁以上不列頁名）：正向 `grep -rl 'ui/staged-ttl-note' src --include=*.html`（命中含本檔自己這一行判準句， 扣掉它就是 include 它的那幾頁）、 反向 `grep -l 'js-staged-ttl-hours' dist/*.html`，兩邊推導出來的頁面集合相同。 **零參數**：這句話在每一頁都一模一樣，版位也一樣（區塊上緣的一行灰字）。 完整的理由（為什麼非講不可、哪一頁最會咬人）寫在 1-1-3 的 include 處，這裡不抄第二份。 **時數走資料節點、不進譯文**（§4-2「翻譯字串不內嵌會隨資料變動的數字」）：那是執行期才 知道的設定值，切版畫當前值、React 由讀回來的值覆寫 `.js-staged-ttl-hours`。 前後綴各一顆 key，空白由 key 自帶（`「…伺服器上：」` 後面不留字面空白， `「 小時內…」` 自帶前導空白）。 #}
