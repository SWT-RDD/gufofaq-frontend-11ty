{# 展示片段：元件庫頁（`pages/components/component.html`）的按鈕那一節 include 它， 示範 `.has-tooltip` ＋ `.tooltip` 這一對怎麼組。 ⚠️ **生產的 `.has-tooltip` 一定還要有自己的可及名稱**（`aria-labelledby` 或另一顆 `.sr-only`）： tooltip 是視覺提示、不是名稱，照這份展示片段抄會做出一顆無名的圖示鈕。逐字契約見 `_tooltip.scss` 檔頭。 #} {# 分工：`.tooltip` 只負責那顆氣泡的樣子（見 `_tooltip.scss`），**它自己不管顯示時機**； 時機由 host（放它的那顆按鈕）掛 `.has-tooltip` 決定——`.has-tooltip:hover .tooltip` 與 `:focus-visible` 兩條規則把 opacity 打開。host 同時提供 `position: relative` 這個定位基準。 #}
