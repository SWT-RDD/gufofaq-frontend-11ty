{# 觸發方式：任何元素掛 data-toast（＋選填 data-toast-type）即可，由 toast.js 的事件委派接手（§5 不寫 inline onclick）。 type：success（預設）/ error / warning / info。需搭配 layouts/base/base.html 裡的 #toastContainer。 元件 js 若要在別的時機彈，呼叫全域 showToast(message, type, duration)。 **什麼時候在 markup 掛 data-toast**（現行規則見 GUIDELINE §5）：送 API 的直接動作鈕以 `|` 列出**所有** 可能結果（data-toast-type 同序對位、每點一次輪播下一個）——設計師才看得到成功/失敗/警告各長什麼樣； 說謊的是「只演成功那一種」。條件開窗鈕與業務值載體不掛（hook class 標記 React 接手）。 以下四顆是型別展示（showcase，不譯）。 #}
{# 複製**不是**「前端就確定」的結果，所以是成功／失敗兩段（與真的複製鈕 .copyBtn / .shareBtn 同形）： `navigator.clipboard` 只在安全脈絡存在，內網 http／file://／使用者拒絕過權限時它整個是 undefined，`execCommand` 那條退路也會丟例外。只演成功那一段，等於在複製沒成功的那一次 彈一顆綠勾——而其中一顆複製鈕是 show-once 的機器憑證明碼（5-6-3，DB 只留雜湊）， 那一次失敗就是那把金鑰永久遺失。 #}
