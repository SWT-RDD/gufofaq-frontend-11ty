  • 平板欄位間距：目前有.sm-gap-4, .sm-gap-8, .sm-gap-10, .sm-gap-12, .sm-gap-16, .sm-gap-20, .sm-gap-24, .sm-gap-32可使用，數字為間距的px數，加在.flex-row.mobile-column上即可

  • 垂直間距（區塊與區塊之間）：.mt-數字（margin-top）、.mb-數字（margin-bottom）、.my-數字（上下同時），數字尺標同 gap（4, 8, 10, 12, 16, 20, 24, 32, 40）；歸零用.m-0。不要寫行內 style="margin-..."（詳見 GUIDELINE §4）；水平間距一律交給.flex-row 的 gap-*

Abstract
Dynamic languages such as JavaScript are more difficult to com- pile than statically typed ones. Since no concrete type information is available, traditional compilers need to emit generic code that can handle all possible type combinations at runtime. We present an al- ternative compilation technique for dynamically-typed languages that identifies frequently executed loop traces at run-time and then generates machine code on the fly that is specialized for the ac- tual dynamic types occurring on each path through the loop. We have implemented a dynamic compiler for JavaScript based on our technique and we have measured speedups of 10x and more for certain benchmark programs.
