{# 這一頁的兩種**打不開**態。兩者都不是「這個檔是空的」，而下一步完全不同： · `dataset.fileNotLinkable`——這個檔匯入時沒有留下擷取管道記錄（3-1-3 的刪除鈕擋在 同一個原因上），要看內容只能重新匯入。 · `dataset.noExtractedContent`——擷取還沒完成，或這個檔裡沒有解得出來的文字。等一下再來 與「這個檔沒有內容」是兩件事，所以兩種原因都要講。 兩句的繁中正本都在切版，這裡的 `.hidden` markup 就是它們的**位置與字色規格**， React 不另造 key（切版是唯一真實來源）。做成 `.hidden` ＋ live region 是因為這一頁本體 只畫得出成功那一態，這兩態要由 React 在執行期切開；可見處在元件庫頁的 「React 條件文案」區（§5）。 #}

{# 表單內容（模擬 table）：一個 `form-table-wrap` 底下只有一組 `form-table-group`（不分小節、 沒有 subtitle），六個固定欄位是 標題／時間／頻道／類型／供應商／內容；class 結構整組走 ui/form-table 的既有正本（§1-2：不另立第二種寫法），只換成示範資料。 **這一頁讀得到的東西逐項交代**（§3-2：讀得出來的每一項都要有地方畫，不畫的寫明理由）： · 檔名 → 麵包屑最後一層 ＋ `.page-title`，並且是「標題」那格的退路（第一個區塊沒有 自己的標題時退它） · 檔案類型 → 「類型」那一格（大寫） · 區塊總數 → 標題下面那一行（理由見該行註解） · 區塊 → 這一頁只畫**第一個**區塊的欄位（標題／日期／內容／檢索用字串）；逐塊全列 是另一種畫面，這一頁的定位是「看一眼這個檔抽出來長什麼樣」 · 檔案識別碼 → 不畫：它就是網址上的 `?sn=`（3-1-3 檔案列的列鍵、進到這一頁的憑據）， 再印一次不會讓任何人多做得了一個決定 · 文件識別碼 → 不畫：索引內部重算出來的雜湊，使用者讀不懂也用不上；查問題走日誌 ⚠️ **「頻道」與「供應商」兩格畫「—」，那是實話不是偷懶**（§6：演的必須是一個真實可能的狀態）。 一個區塊身上只有序號／標題／日期／內容／檢索用字串——頻道（來源資料集名稱）與供應商都不在 裡面。那兩欄是 **Excel 匯入才有**的動態欄，而 excel 檔一律導去 3-1-6 的對照畫面（excel 一列 就是一份文件，這一頁「一份文件切成很多塊」的模型不適用）——所以走得到這一頁的檔案結構上 不可能有這兩欄。**不可以填「客服問答知識庫／自行上傳」這種值**——那是憑空造了兩個取不到的 東西，而示範資料一旦說謊，這一頁就再也驗不出對照有沒有接錯。 **「這兩格要有真值」是切版在這裡主張的需求**（§4「切版主張需求，不等資料到齊」）。 要求的內容：每一個區塊都要帶得出來源資料集與供應商兩欄。 為什麼非它不可：使用者正是靠這兩欄判斷「這一份是從哪裡來的、誰產的」，而現在兩格都答不出來。 **兩態都切**：拿不到畫「—」（不是留白——留白會被讀成「這一份沒有頻道」），拿得到畫值。 ⚠️ **這六格 `.th` 是 chrome，照掛 `data-i18n`**——「租戶自取的顯示名是資料不是 chrome」那條 裁決本身成立，但它的消費點是 3-1-6、不是這一頁：那一頁的欄標籤真的是租戶自己取的（讀得到 租戶設定的欄位顯示名），所以那一頁一顆 `data-i18n` 都不掛、label 由 `{% set %}` 給。 而這一頁**讀不到任何租戶顯示名**，這六格是固定欄位的固定標題；真正動態的那一族（區塊內容 那一包的其餘鍵）是拿**原始鍵**當標題、不翻——那才是裁決講的那一種。 #}
