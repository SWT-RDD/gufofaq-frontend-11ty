→ `default-table` ＋ accordion 詳細列 → `pager-row`）。**這段檔頭就是本頁的設計正本**——設計階段的 spec 與實作計畫不進版控， 端點契約、旋鈕取捨、以及**這一頁刻意沒有的東西**全部寫在下面。 ───────────────────────────────────────────────────────────────────────────── **這一頁打的是 gufofaq-saas product，而檢索本身的能力邊界由 GufoRAG `manager_backend` 決定** ——兩層都要看：瀏覽器打不到 GufoRAG，product 是代理；而「這一頁畫得出什麼旋鈕」問的是上游 接不接得住。**這一頁只留接得住的那些**：一個檢索頁看起來該有的東西（進階篩選、排序、摘要、 存入資料集⋯）大半在這裡沒有入口，逐條理由寫在下面「這一頁刻意沒有的東西」——不寫的話， 下一個人分不出那是「不能」還是「還沒」。 端點清單（動詞 ＋ 路徑 ＋ 符號 ＋ 型別）： product POST /search/documents `search_documents` SearchIn → DocumentSearchOut（本頁唯一送出的請求） product GET /datasets `list_datasets` （檢索範圍窗的清單來源，見該元件檔頭） 上游 POST /api/v1/search `search()` SearchManagerRequest → SearchResponse（product 代打） **送出的參數面就這些**（型別正本＝product 的 `SearchIn`）： SearchIn query｜dataset_ids[]｜strategy｜start_date｜end_date｜page｜page_size `SearchIn` 帶 `model_config = ConfigDict(extra="forbid")`，上游的 `SearchParams` 也是 ⇒ **多送一個沒宣告的欄位是 422／400、不是被忽略**。這一條是下面每一條「刻意沒有」的總依據： 畫得出來卻送不出去的旋鈕，在這條路上不是「還沒接」，是送出即失敗。 **回應是投影、不是轉發**：`DocumentSearchOut` 只有 `total`／`returned`／`elapsed_ms`／`rows`， 而一列（`SearchRowOut`）只有四欄——`document_id`｜`doc_name`｜`date`｜`abstract`，恰好是這一頁 畫得出來的那些。上游 `SearchResult` 的其餘欄位在 product 那一層就被擋掉了：`data_source` 是 伺服器上的絕對路徑、`index` 是內部索引名，兩者都不該進瀏覽器。 ───────────────────────────────────────────────────────────────────────────── **「檢索模式」兩顆改綁 `strategy`，並補上第三顆**（§5：切版刻意不照搬 某段既有行為時，要在該頁檔頭記載什麼取代了什麼）。三顆的 `value` 逐字取自上游的 `SearchStrategy` enum，而 product 的 `SearchIn.strategy` 以同一組 `Literal` 夾住它 （值域寫成 `Literal` 而不是裸 `str`，是為了讓它出現在 OpenAPI 上）： 畫面 strategy 實際打誰 混合檢索 hybrid 兩個引擎都打再合併（**`SearchManagerRequest.strategy` 的預設值**） 關鍵字檢索 gufonet_only GufoNet BM25（GufoNet 那一側） 語意檢索 weaviate_only Weaviate `near_vector`（Weaviate 那一側的非同步 `search()`） 補第三顆是**必要的誠實**、不是加功能：`strategy` 的預設就是 `HYBRID`，只畫兩顆等於畫面上 表達不出後端的預設態，使用者一進來看到的勾選狀態會是假的。三顆的預設勾在「混合檢索」。 **「開始／結束時間」兩欄送的是日期本身（`SearchIn.start_date`／`end_date`），不是 DSL**： 組 `$filterDate >= '…' and $filterDate <= '…'` 的是 product（`build_date_range_dsl`）， 前端一個字都不拼。`filterDate` 是上游 `DEFAULT_FILTER_FIELD_NAMES` 六欄之一。 **這件事決定了「結束時間早於開始時間」是誰擋的**：product 回 400 ＋ `code: date_range_reversed`， 不是前端送出前自己發現的（見下方查詢鈕那一段）。 ⚠️ **前提是匯入 pipeline 的 mapper 有把日期寫進 `filterDate`**——沒寫的資料集這兩欄篩不到東西， 而那是資料面的事、畫面上看不出來——所以結果表的空狀態要把這件事說出來。 **檢索範圍逐一列舉，沒有「空＝全部」這一態**：`SearchIn.dataset_ids` 帶 `min_length=1`， 缺席或空陣列是 422。**「檢索全部」＝在檢索範圍窗按全選、把每一個 id 都送出去。** 理由在上游：`SearchParams.indexes` 空值是「不加索引條件」（GufoNet 那一側的 `_build_query_sentence()` 是 `if search_params.indexes:`），而 manager 沒有租戶概念 ⇒ 那一層的「全部」是**全平台**。product 有能力把空清單翻譯成「本租戶全部」，但只要那個值 還在契約上，少翻一次就是跨租戶檢索、而回應看起來完全正常——所以值域收在**送出的那一端**。 由此三件事：檢索範圍窗一筆都沒勾時確認鈕 `disabled`（見該元件檔頭）、查詢鈕多一段 「沒有選擇資料集」的 warning（這個租戶一個資料集都沒有時按得到）、觸發鈕的 0 態**照數字印 「已選 0 個資料集」**——0 不再是「全部」的別名，照著印就是真話。 **進頁時預設全選**（給 React 的契約）：值域收緊之後，不預設就等於每次進來都要先開一次窗。 ───────────────────────────────────────────────────────────────────────────── **這一頁刻意沒有的東西**（GUIDELINE §4「不做的那些在檔頭寫明理由」）： · **「檢索功能」六顆 radio**（標準字／同義／容錯／原形字／模糊／自然語言）與它的依賴說明： 那三個參數（`SearchMode`／`SameMeaningMode`／`SimilarMode`）在新後端**沒有任何入口**， 且 GufoNet 那一側的 `search()` 與非同步 `search()` 都把 `SearchMode` **寫死 "2"**（主題查詢）。 · **「只搜尋第一段」**：沒有這個參數；`chunkIndex` 屬 `RESERVED_SYSTEM_FIELD_NAMES` （`RESERVED_SYSTEM_FIELD_NAMES`），DSL 明文不可引用它。 · **關鍵字自動完成**（`components/autocomplete-input` 那一顆）：這個後端零 suggest 端點。 元件本身留著（元件庫頁仍有示範），只是這一頁不再用它。 · **「各最長 1000 字」提示**：`query` 只有 `min_length=1`，沒有上限；有 `max_length` 的是 `filter`（4096），而那串是 React 組的、不是使用者打的 ⇒ 沒有值域可以先告訴使用者。 · **進階篩選（facet 卡）整區**：兩個引擎那兩支只有 `total_count` 的 aggregate， 沒有任何 group-by／facet ⇒ 逐值 count 產不出來。要保留「用自訂欄位縮小範圍」的話是**改寫** （拿 `GET /system/filter-fields` 的欄位定義組 DSL 條件、沒有計數），不是保留這一區。 · **排序下拉四顆**：`SearchParams` 沒有排序欄位（且 `extra=forbid`）；GufoNet 那側寫死 `SortField: "$TF$:-"`，而 `WeaviateSearcher.search()` docstring 自己註明「向量搜尋不支援排序」。 · **「命中處數」欄與「命中 N 處」總計**：GufoNet 那一側的 `_BASE_CONTENT_FIELD` 只取 `$Score$`，**沒有 `$TF$`** ⇒ TF 整個不回。 · **「顯示圖片」開關與縮圖**：沒有縮圖來源欄位（連同 `ui/doc-search-block` 一起刪）。 · **「存入資料集」與「匯出整份檔案」**：新後端沒有 DocCollection 概念、也沒有 `DownloadSearchResult` ⇒ `components/store-to-collection-modal` 整顆刪。 · **逐列勾選框與表頭全選**：唯一的消費者是「存入資料集」，那顆沒了它們就是零消費者的控制項。 · **檔名的三態**（下載原檔／看欄位內容／純文字）：`DownloadOriginalFile` 與 `RetreiveContent` 兩支都沒有對應 ⇒ 檔名降成純文字，`components/field-content-modal` 整顆刪。 · **「標題」欄**：`SearchResult` 沒有 title。GufoNet 那側的 `TfFieldWeight` 給 `$Title$` 開了權重 證明索引裡有 Title，但它沒被寫進 `_BASE_CONTENT_FIELD`、也沒被 `_convert_to_search_result` 取出來 ⇒ 值拿不到。 · **明細列的自訂欄位逐欄**（發布單位／原始連結）：`_build_content_field()` 確實會把自訂欄位 append 進 GufoNet 的 `ContentField`，但 {# 值域寫在填之前（§3-2），而這一段講的是「篩得到什麼」而不是格式：時間篩的是匯入時寫進 `filterDate` 的那一欄，沒寫的資料集這兩欄篩不到東西——那是使用者看得懂、也換得掉 （改挑資料集）的狀況，不能等按下查詢才由 toast 說。 #}

時間篩的是匯入時寫入的文件日期；沒有寫入日期的資料集，這兩欄篩不到任何結果。
