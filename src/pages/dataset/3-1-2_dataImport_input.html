{# 資料集名稱輸入：一顆純文字輸入框 `#datasetName`，走全站表單既有的 `.form-control` 寫法， 不另立版型（§1-2）。 **必填要成對標**（§4：`control-label required` 與控制項的 `required`——星號是視覺，`required` 是報讀器與 React 表單庫讀的那一份）：上游 `create_dataset` 的第一道就是 400 `dataset.name_required`（product），而這一頁的送出鈕自己也列著 「資料集名稱不可為空」；同一張表單的「所屬群組」與姊妹頁 3-3／3-2／3-6 的名稱欄都標了。 #}
{# 空的 live region：錯誤文字由業務 js 填入。.error-prompt 預設就 display:none（由父層 .error 顯示），不必行內再寫一次 #}
{# 所屬群組：資料集歸屬一個群組（SaaS 群組權限需求，見 product DatasetIn.group_id 為必填）。 執行期由業務 js 載入「這個人可以寫入的群組」（租戶管理者＝本租戶全部）填進選項，單選； 切版這一份用原生 select ＋ 兩筆示範選項演版型。 #}
{# **一個可寫入的群組都沒有**那一態：這顆 select 的選項是「我有 data:write 的群組」， 一個都沒有時它就是空的——而一顆只有「請選擇群組」的下拉，讀起來像「還沒挑」而不是 「你沒得挑」，使用者會一直找那個不存在的選項。所屬群組是必填（product 的 `DatasetIn.group_id`），所以這一態等於整張表單送不出去， 要講得出解法（找租戶管理者建群組並把你加進去）。 這一句的繁中正本在切版——`.hidden` 的這一份就是它的位置與字色規格，React 不另造 key； 可見處在元件庫頁的「React 條件文案」區（§5）。 #}

你沒有任何可以寫入的群組，所以建不了資料集。請找租戶管理者建一個群組並把你加進去。

{# 切塊設定：`POST /datasets` 的 `DatasetIn` 三欄——`chunk_size`／`chunk_overlap`／ `prepend_title_each_chunk`（product）。 **為什麼非畫不可**：`DatasetIn` 收得下這三個參數，而它們決定這個資料集之後**所有**檔案怎麼被切 （§3-2：request 收得下的每個參數都要在畫面上有落點）。少了落點，這個決定就只能靠直接打 API， 而使用者連它存在都不知道。 **為什麼版位在建立頁**：`_assert_chunk_params_still_settable`（同一支模組）是一道 409 硬閘門——這個 資料集只要做過一次走 folder 管道的「檔案上傳」匯入，三欄就再也改不動（folder 管道每資料集 一支、建立時參數就固定，product 沒有任何路徑會刪它），所以「現在」是唯一保證改得動的時機。 3-1-3 詳細頁另有一份（走 `PATCH /datasets/{id}` 的 `DatasetPatchIn`），那裡才撞得到 409。 **值域出處**（§4 數字欄三件套的常數來源，同一支模組）：`_CHUNK_SIZE_MIN` = 100／`_CHUNK_SIZE_MAX` = 8000 收在 `DatasetIn.chunk_size` 的 `Field(ge=…, le=…)`，預設 1000；`chunk_overlap` 是 `Field(default=200, ge=0)`——**上界不是常數**，而是跨欄約束 `_assert_overlap_below_size` （overlap 必須小於 size，違反回 422），所以 max 不寫死、由可見提示承載那句話； `prepend_title_each_chunk` 預設 False。三欄都是整數／布林 ⇒ step="1"。 **值載體不另創 hook class**：本表單既有的 `#datasetName`／`#datasetGroup` 都是純 id 契約 （React 正本 apps/web `datasets/new/page.tsx` 直接讀自己的 state 送 body），三顆新欄位沿用 同一種記號（§5 矩陣：class 或 id 擇一）。送出動作是下面那三張卡片（React 端＝先 POST /datasets 帶這三欄、再導去該類型的上傳流程），故本區塊沒有自己的送出鈕。 ⚠️ 那幾張卡因此是**送出鈕**、不是連結——見下方 `uploadCardAction` 那一段。整頁零 data-toast、 零 data-capability，就是把一次會 400／403／409 的建立演成一條必然成功的連結。 #}
