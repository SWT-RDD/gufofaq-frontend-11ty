{# 資料集名稱輸入：一顆純文字輸入框 `#datasetName`，走全站表單既有的 `.form-control` 寫法， 不另立版型（§1-2）。 **必填要成對標**（§4：`control-label required` 與控制項的 `required`——星號是視覺，`required` 是報讀器與 React 表單庫讀的那一份）：名稱空著送出會被擋下並指名是這一欄，而這一頁的 送出鈕自己也列著「資料集名稱不可為空」；同一張表單的「所屬群組」與姊妹頁 3-3／3-2／3-6 的名稱欄都標了。 #}
{# 空的 live region：錯誤文字由業務 js 填入。.error-prompt 預設就 display:none（由父層 .error 顯示），不必行內再寫一次 #}
{# 所屬群組：資料集必須歸屬一個群組，這一欄是必填（群組是寫入權限的單位）。 執行期由業務 js 載入「這個人可以寫入的群組」（租戶管理者＝本租戶全部）填進選項，單選； 切版這一份用原生 select ＋ 兩筆示範選項演版型。 #}
{# **一個可寫入的群組都沒有**那一態：這顆 select 的選項是「我有 data:write 的群組」， 一個都沒有時它就是空的——而一顆只有「請選擇群組」的下拉，讀起來像「還沒挑」而不是 「你沒得挑」，使用者會一直找那個不存在的選項。所屬群組是必填，所以這一態等於整張表單送不出去， 要講得出解法（找租戶管理者建群組並把你加進去）。 這一句的繁中正本在切版——`.hidden` 的這一份就是它的位置與字色規格，React 不另造 key； 可見處在元件庫頁的「React 條件文案」區（§5）。 #}

你沒有任何可以寫入的群組，所以建不了資料集。請找租戶管理者建一個群組並把你加進去。

{# 切塊設定：建立資料集時一起送出的三欄——切塊大小／切塊重疊／每一塊都帶上文件標題。 **為什麼非畫不可**：建立資料集這一步收得下這三個參數，而它們決定這個資料集之後**所有**檔案 怎麼被切（§3-2：收得下的每個參數都要在畫面上有落點）。少了落點，這個決定就只能靠直接打 API， 而使用者連它存在都不知道。 **為什麼版位在建立頁**：這是一道硬閘門——這個資料集只要做過一次「檔案上傳」匯入，三欄就再也 改不動（那條匯入管道每個資料集一支、建立時參數就定案，沒有任何路徑會把它刪掉重來）， 所以「現在」是唯一保證改得動的時機。3-1-3 詳細頁另有一份，那裡才撞得到「已經定案、改不動」 那一態。 **值域在這裡宣告**（§4 數字欄三件套）：切塊大小 100–8000、預設 1000；切塊重疊下限 0、預設 200 ——**上界不寫死**，因為它不是一個固定數字而是跨欄約束（重疊必須小於切塊大小，違反會被擋下）， 那句話由可見提示承載；每一塊都帶上文件標題預設關。三欄都是整數／布林 ⇒ step="1"。 **值載體不另創 hook class**：本表單既有的 `#datasetName`／`#datasetGroup` 都是純 id 契約， 三顆新欄位沿用同一種記號（§5 矩陣：class 或 id 擇一）。送出動作是下面那三張卡片（按下去 先帶著這三欄建立資料集，成功才導去該類型的上傳流程），故本區塊沒有自己的送出鈕。 ⚠️ 那幾張卡因此是**送出鈕**、不是連結——見下方 `uploadCardAction` 那一段。整頁零 data-toast、 零 data-capability，就是把一次擋得下來的建立演成一條必然成功的連結。 #} {# 欄位組與它的 ⓘ 說明窗的正本在 `components/chunk-settings`：這一頁與 3-1-3 是同一份設定的 兩個入口，欄位、值域提示與那兩句代價說明必須逐字相同（理由見該元件檔頭）。 `mt-16` 是這一頁的版位（上一區是資料集名稱與群組）；**不畫儲存鈕**——這一頁的送出動作是 下面那三張 upload-card，這裡多一顆就是兩個送出點。 #} {% set chunkSettingsBlockClass = "mt-16" %} {% set chunkSettingsSubmit = false %} {% include "components/chunk-settings/chunk-settings.html" %} {# 卡片的去向：excel→1-1-2、pdf／word→1-2-1。執行期這一步是「先建資料集 （送出名稱＋群組＋上面那三個切塊參數），成功之後才導到該類型的上傳流程」， 切版只演跳轉那一半（§5：不在切版範圍的互動不做）。 #} {# 這三張卡（Excel／PDF／WORD，見 ui/upload-card 檔頭）是**這一頁唯一的送出動作**， 按下去就是建立這個資料集，結果有這幾種： ・沒有 data:write 權限 ・名稱不可為空 ・選到的群組不存在 ・那個群組你沒有寫入權 ・同名資料集已存在 ・建索引那一步失敗 成功之後才導去卡片自己的 `data-href`；那顆屬性是 §5 的轉換契約，不因為換成 button 就消失。 #} {% set uploadCardAction = true %} {% set uploadCardCapability = "data:write" %} {% set uploadCardToast = "資料集已建立，接著上傳檔案|權限不足，無法建立資料集——請找貴租戶的管理者開通|資料集名稱不可為空|選到的群組不存在，請重新選一個|你在這個群組沒有寫入權限，請換一個群組或找管理者開通|同名的資料集已經存在，請換一個名稱|建立失敗，請稍後再試|此功能尚未對貴租戶開通，請聯絡平台管理員" %} {% set uploadCardToastKey = "toast.createDataset" %} {% set uploadCardToastType = "success|warning|warning|warning|warning|warning|error|warning" %} {% include "ui/upload-card/upload-card.html" %}
