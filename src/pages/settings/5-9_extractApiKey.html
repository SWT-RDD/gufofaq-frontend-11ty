{# 萃取 API 金鑰管理（獨立設定頁）。SaaS 新需求，逆向自 product extract.py： 每租戶一把金鑰，供外部程式以 X-API-Key 標頭呼叫萃取端點（國家／時間）與資料 API （/api/v1）；重新產生後舊金鑰立即失效。/api-key 的 GET／POST 皆僅租戶管理者可用 （require_admin，比照 widget-tokens）。 **明碼只在產生的那一次出現**：product 端只存雜湊，重新載入後只回得出末四碼 hint。 故本頁有兩種態：剛產生（顯示完整金鑰＋「唯一一次」警語，顯示/隱藏可用）與 已存在（只顯示 hint＋「只保存雜湊」說明，顯示/隱藏無意義）。 無金鑰首次態（尚未產生）由 React 依 API 呈現，切版以「剛產生」態示範。 #}

{# 如何呼叫：說明 + 可複製 curl 範例 #}
如何呼叫萃取 API

以 X-API-Key 標頭呼叫；mode 1=國家、2=時間、3=兩者；text 長度 2–5000 字；額度用罄回 429。

curl -X POST "https://<your-host>/api/extract/country-or-time" \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"我們下週三在東京開會","mode":3}'
